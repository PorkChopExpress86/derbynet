{# The server's time zone and how to change it (D56). No setting stores it: it comes from DERBYNET_TIME_ZONE or TZ when the server starts. #}

Time zone: {{ tz.name }}{% if tz.source %} (from {{ tz.source }}){% else %} (neither DERBYNET_TIME_ZONE nor TZ is set){% endif %}

Heat times and results use this zone. To change it, set DERBYNET_TIME_ZONE (or TZ) to a zone name such as America/Chicago in the Docker container's environment, then restart the server. Docker on Windows has no local zone to read, so the server runs on UTC there until you set it.
